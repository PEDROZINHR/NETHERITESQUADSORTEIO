TRANSPARÊNCIA DO SORTEIO

O sorteio usa o gerador criptográfico do navegador (crypto.getRandomValues) com rejeição de valores enviesados. Cada dupla e cada bioma só pode sair uma vez. O código fica aberto para qualquer participante conferir.

1. Os 10 participantes são embaralhados individualmente. Cada nome é sorteado em um giro e removido da roleta; o segundo giro completa a dupla.

2. Depois dos dois nomes, um giro separado escolhe o bioma da dupla. Os nomes e biomas sorteados são removidos das respectivas roletas.

3. Os 8 biomas entram uma única vez. Como são 5 duplas, 3 biomas ficarão de fora.

4. Não existe botão para escolher um resultado específico. Para recomeçar, o sorteio inteiro é reiniciado.
